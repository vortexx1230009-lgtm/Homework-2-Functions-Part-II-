# Student Management System (Chapter 8: Functions — Part II)

A modular Python application developed for a university Student Management System. This project demonstrates passing lists to functions, handling arbitrary positional arguments (`*args`), organizing code into reusable modules, adhering to PEP 8 style guidelines, and writing automated unit tests with `unittest`.
